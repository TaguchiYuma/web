## About

現在は、株式会社豊田中央研究所で研究業務に従事しています。現在の主な研究テーマは以下です。

- 次世代移動体通信の車両活用
- 大規模イベント時の群衆マネジメント

また、過去に取り組んだテーマは以下のようなものがあります。

- 車両データを活用した交通量推定
- 大規模非線形進化力学系の統計力学的解析
- 腸内細菌叢の数理モデルのパラメータ推定とその相互作用の解析
